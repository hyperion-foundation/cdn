## Hyperion Foundation CDN (Dev version)
A website to store our contents (e.g. gaming contents, etc).

## Tech Stack & Branch Information
On this branch, we are remaking and testing our CDN website by using only [Next.js](https://nextjs.org) with **App Router**. We are trying to drop [Nextra](https://nextra.site) framework. If our testing meet our expectation, this website version will be released to the `main` branch, which is our main/stable CDN website.

Tech stack list:
- [Next.js](https://nextjs.org) - React framework
- [Tailwind CSS](https://tailwindcss.com) - CSS styling
- [GSAP](https://gsap.com) & [styled-components](https://styled-components.com) - Animation tools
- [Radix UI - Icons](https://radix-ui.com/icons) - Icons
